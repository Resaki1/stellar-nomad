# Star catalogue data — source and licence

`stars_visual.bin` and `stars_nearby.json` are generated by
[`scripts/build_star_catalogue.py`](../../scripts/build_star_catalogue.py) from the
**HYG star database v41**.

- Source: <https://codeberg.org/astronexus/hyg> (previously
  <https://github.com/astronexus/HYG-Database>)
- HYG is a merge of the **Hipparcos** catalogue, the **Yale Bright Star Catalogue (5th ed.)** and the
  **Gliese Catalog of Nearby Stars**, with parallax-derived distances and pre-computed Cartesian
  positions.
- **Licence: Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0)** —
  <https://creativecommons.org/licenses/by-sa/4.0/>

## ⚠ Open decision — share-alike

CC BY-SA is a **share-alike** licence, and the two generated files are derivative works of it. Shipping
them therefore carries both the attribution requirement and the share-alike obligation *for those
files*. That is a normal and widely-used arrangement — the data file is licensed BY-SA, the surrounding
code is not — but it is a distribution decision that should be made deliberately rather than by default.

**If share-alike is unacceptable**, the primary sources are not share-alike and the build script is a
straight swap (see its module docstring):

| catalogue | VizieR id | terms |
|---|---|---|
| Yale Bright Star Catalogue, 5th ed. | V/50 | freely usable with citation (Hoffleit & Warren 1991) |
| Hipparcos, van Leeuwen 2007 re-reduction | I/311 | ESA, freely usable with acknowledgement |

HYG was chosen for the first pass only because it already merges those sources *and* pre-computes
distances and Cartesian positions, which is exactly the record shape
[`docs/STAR_CATALOGUE_PLAN.md`](../../docs/STAR_CATALOGUE_PLAN.md) §3 specifies.

## Regenerating

```bash
curl -L -o /tmp/hygdata_v41.csv \
  https://raw.githubusercontent.com/astronexus/HYG-Database/main/hyg/CURRENT/hygdata_v41.csv
python3 scripts/build_star_catalogue.py /tmp/hygdata_v41.csv
```

The 34 MB source CSV is deliberately **not** committed — only the 174 KB derived blob is.
